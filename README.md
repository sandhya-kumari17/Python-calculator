
# Python Calculator

A command-line calculator I built while learning Python.

## What it can do
- Two numbers: + - * / // % ** avg percent
- One number: sqrt, abs, !, log, sin, cos, tan (angles in degrees)
- Keeps running until you type quit
- Handles wrong input and divide by zero without crashing

## How to run
1. Install Python
2. Download calculator_project.py
3. Open a terminal in that folder and run: python calculator_project.py

## Example
Enter operator: +
Enter first number: 5
Enter second number: 3
Result: 8.0

Enter operator: sqrt
Enter number: 16
Result: 4.0

Enter operator: quit
Goodbye! Thank you for using calculator
